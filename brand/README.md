# Brand

The Ankor logo is an italic A whose crossbar runs past its legs as an anchor's stock. The wordmarks
wrap the gear from the Rust logo, from
[rust-lang/rust-artwork](https://github.com/rust-lang/rust-artwork) under its CC-BY license, around
the R. The files are not covered by the repository's code licenses, as [LICENSE](LICENSE) states. Their text is
outlined, so the files need no fonts. The docs site keeps a copy of `ankor-wordmark.svg` in
`docs/public`, because it reads nothing outside its package; copy it again when the wordmark changes.

| File                            | Use                                                                           |
|---------------------------------|-------------------------------------------------------------------------------|
| `ankor-wordmark.svg`            | The wordmark, on dark backgrounds.                                            |
| `ankor-wordmark-sh.svg`         | The wordmark with `.sh`, for the domain.                                      |
| `ankor-mark.svg`                | The A alone, on dark backgrounds.                                             |
| `*-light.svg`                   | The same three for light backgrounds.                                         |
| `ankor-mark-on-accent.svg`      | The A reversed out of the accent blue.                                        |
| `ankor-mark-on-accent-1024.png` | The same at 1024 px, for avatars.                                             |
| `ankor-spectator-360x60.png`    | The image `sv_server_graphic1` shows spectators: `MATCH PLAYED ON` and `.sh`. |
| `gearopen.py`                   | Adds the gear to a plain wordmark.                                            |

- Colours: text `#eceef1`, or `#0c0d0f` in the light variants; stock `#4a65e0`; `.sh` `#5e78e6`;
  gear `#2f44a3`. On the accent, the A is `#eef1ff` and the stock `#0c0d0f`.
- The wordmark is Barlow Condensed ExtraBold Italic, uppercase, tracked `.03em`.
